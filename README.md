I'm **Airon**. I build local-first tools for AI agents, phones and the browser, and I run them on my own servers. Most of that work is private; these are the open ones.

- **[Cellar](https://github.com/Airn0x/Cellar)** — the server room in your cellphone. Turns any unrooted Android phone into a Linux server for AI agents, with a native console. *Kotlin, pre-alpha*
- **[real-keyboard-lab](https://github.com/Airn0x/real-keyboard-lab)** — types into a web page with the phone's real on-screen keyboard, in CI, so autocorrect and auto-capitalisation actually run. *Python*
- **[Aion](https://github.com/Airn0x/Aion)** — a private, AI-powered personal operating system that runs entirely on your own machine. *Python, desktop app*

**Tools:** Python · TypeScript · Kotlin · Linux · Docker · nginx
